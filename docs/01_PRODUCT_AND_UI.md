# 01. 제품과 화면 명세

문서 버전: 1.0 | 작성 기준: 2026-09-30 | 상태: 설계 명세 (실제 구현·검증 상태는 문서 05 참조)

## 1. 제품 정의

**StockLab은 국내 주식의 가격 흐름, 실제 공시 재무정보, 기업 비교, 개인의 판단 기록을 연결하는 리서치 웹이다.**

이 프로젝트의 1차 목적은 웹 프론트엔드 포트폴리오다. 방문자가 설치나 회원가입 없이 핵심 화면을 체험할 수 있어야 한다. 2차 목적은 작성자가 로컬에서 한투의 실제 시세를 연동하고 스트림 처리와 데이터 정합성을 검증하는 것이다.

### 보여주려는 역량
- 캔들, 호가, 체결 목록이 동시에 변해도 입력과 화면 탐색을 방해하지 않는 실시간 UI
- 서버 데이터, 고빈도 시장 데이터, 화면 상태, 개인 데이터의 구분
- 재무 수치의 기간과 출처를 보존하는 정규화 및 시각화
- 검색, 비교, 관심종목, 메모로 이어지는 완성된 사용자 흐름
- 오류 처리, 테스트, 접근성, 데이터 라이선스와 비밀정보 보호를 포함한 배포

이는 개발 목표다. 실제 성능 개선이나 채용 효과가 검증되었다는 주장이 아니다.

## 2. 모드와 데이터의 의미

| 구분 | 개발 초기 | 개인 로컬 연동 | 공개 Vercel |
|---|---|---|---|
| 시세, 캔들, 호가, 체결 | 직접 생성한 합성 데이터 | 한투 실제 데이터 | 직접 생성한 합성 데이터 |
| 기업 재무정보 | 명확히 표시한 예시 | OpenDART | 검토된 OpenDART 캐시 |
| 공시 목록 | 명확히 표시한 예시 | OpenDART | 검토된 OpenDART 캐시 |
| 관심종목, 메모 | 브라우저 저장 | 브라우저 저장 | 방문자 본인 브라우저 저장 |
| 클라우드 동기화 | 없음 | 후속 단계 | 후속 단계의 Supabase 로그인 사용자만 |

- 공개 시세 표기: `시세 시뮬레이션 — 현재 주가가 아닙니다`.
- 공개 재무 표기: `출처: 금융감독원 OpenDART | 연결 | 사업연도 YYYY | 수집일 YYYY-MM-DD`.
- 초기 예시 재무 표기: `예시 재무정보 — 실제 기업 실적이 아닙니다`.
- 가격과 재무를 같은 종목 페이지에 보여주더라도 데이터 성격을 혼동시키지 않는다.
- 실제 재무와 합성 가격으로 계산한 PER, PBR, 시가총액, 투자수익률은 제공하지 않는다.
- 공시와 합성 주가를 겹쳐서 실제 시장 반응을 분석하는 것처럼 보여주지 않는다.

P4 코드 상태(2026-09-30, 실행 미검증): 재무·공시·비교에 fixture/dart-cache 출처 구분과 미설정·미제공·오류·노후 캐시 표시를 연결했다. 기본값은 fixture이며 실제 공개 자료는 0개다. 실제 캐시는 수집일과 원문을 표시하고 Q4 손익·분기 CF 파생은 아직 제공하지 않는다. 공개 화면은 검색엔진 noindex로 둔다. 실제 데이터 등록·DB 적용·배포는 수행하지 않았다.

## 3. 범위

### MVP 포함

| ID | 요구사항 | 완료 조건 |
|---|---|---|
| P01 | 종목 검색 | 회사명과 6자리 코드로 지원 종목을 찾고 키보드로 이동한다. |
| P02 | 시세 테이블 | 관심종목의 합성 현재가와 등락이 움직이며 출처를 확인할 수 있다. |
| P03 | 종목 상세 | 가격, 캔들, 호가, 최근 체결, 연결 상태를 한 화면에서 본다. |
| P04 | 재무 요약 | 연간 매출, 영업이익, 순이익, 자산, 부채, 자본을 표와 차트로 본다. |
| P05 | 재무 기간 전환 | 연간과 지원하는 분기를 구분하고 연결/별도와 누적 여부를 표시한다. |
| P06 | 공시 타임라인 | 제목, 제출일, 정정 여부를 보고 공식 원문으로 이동한다. |
| P07 | 기업 비교 | 최대 3개 기업의 동일 기간, 동일 기준 재무를 비교한다. |
| P08 | 관심종목 | 로그인 없이 추가/삭제하고 새로고침 후에도 유지한다. |
| P09 | 리서치 노트 | 기업별 판단, 근거, 위험, 확인할 일을 저장하고 다시 수정한다. |
| P10 | 데모 제어 | 일시정지, 재생, 배속, 초기화가 같은 화면에서 동작한다. |
| P11 | 데이터 상태 | 예시, 실제, 오래됨, 미제공, 오류를 서로 다른 상태로 보여준다. |
| P12 | 공개 배포 | 키 없는 공개 시세 데모와 실제 DART 캐시를 Vercel에서 제공한다. |

### 기술 검증 포함
- 개인 로컬 한투 WebSocket 연결, REST 초기 스냅샷, 구독/해제, 재연결
- 파서 계약 테스트, 합성 스트레스 테스트, 렌더링 전후 측정
- 비밀정보 누출 방지와 공개 환경의 한투 접근 차단

### 후속 단계
Supabase 로그인과 기기 간 개인 데이터 동기화, 더 많은 종목, 더 세밀한 재무 표, 자체 생성 시나리오 추가. MVP 완료 전에 이 기능으로 범위를 확장하지 않는다.

### 제외
실제 주문, 모의 주문 엔진, 계좌 잔고, 결제, 포트폴리오 수익률, 해외 주식, 코인, NXT/통합 시세, 파생상품, 뉴스 크롤링, AI 투자 추천, 애널리스트 컨센서스, 유료 데이터 자동 구독.

## 4. 지원 종목과 기간

초기에는 검증 가능한 국내 비금융 보통주 10개 이내로 제한한다. 삼성전자는 첫 수직 기능의 예시 대상이다. 실제 종목코드와 DART 고유번호는 등록 단계에서 공식 데이터로 확인한다.

- 우선주, ETF, ETN, SPAC, 금융업종의 특수 재무구조는 MVP에서 제외한다.
- 종목 목록에 없으면 `현재 데모에서 지원하지 않는 종목입니다`를 표시한다.
- 시세는 KRX 기준만 지원한다. KRX와 NXT 데이터를 섞지 않는다.
- 재무는 최근 공시가 확보된 3개 사업연도와 지원 가능한 최근 4개 분기를 우선한다.
- 구현 시점의 연도를 읽고 실제 제출된 보고서를 기준으로 목록을 만든다. 미래 분기나 미제출 연도 숫자를 만들지 않는다.
- MVP 분기 비교는 12월 결산 법인으로 제한한다. 비12월 결산은 연간 조회만 제공하거나 명확한 미지원 상태로 처리한다.

## 5. 정보 구조

| 경로 | 역할 | 주요 상태 |
|---|---|---|
| `/` | 리서치 홈, 검색, 관심종목 요약 | 최초 진입, 빈 관심종목, 합성 스트림 |
| `/stocks/[symbol]` | 종목 상세 | overview/financials/filings 탭 |
| `/compare` | 기업 비교 | 종목 0~3개, 기간 불일치, 데이터 미제공 |
| `/watchlist` | 관심종목 관리 | 추가, 삭제, 정렬, 브라우저 저장 실패 |
| `/notes` | 개인 리서치 기록 | 검색, 신규, 수정, 삭제, 저장 충돌 |
| `/about/data` | 출처와 한계, 데모 설명 | 시세 합성, DART 실제 여부, 갱신일 |
| `/login` | 후속 클라우드 동기화 | 해당 기능을 활성화했을 때만 표시 |

URL 상태 예시:

```text
/stocks/005930?tab=financials&basis=CFS&view=annual&year=2025
/compare?symbols=005930,000660&basis=CFS&view=annual&year=2025
```

코드는 형식 예시다. 예시에 나온 기업의 실제 수치나 현재 상장 상태를 보증하지 않는다. URL에 잘못된 값이 있으면 안전한 기본값으로 정규화하고 유효하지 않은 종목은 명확히 알린다. 탭, 기간, 비교 대상은 뒤로가기와 새로고침으로 복원한다.

## 6. 화면별 상세

### 6.1 홈

상단에 브랜드, 전체 검색, 관심종목, 비교, 노트, 데이터 설명을 배치한다. 큰 홍보용 히어로 대신 사용 가능한 종목과 최근 열어본 기업을 먼저 보여준다.

주요 영역:
- 항상 보이는 시세 모드 배지와 `데이터 설명` 링크
- 검색 입력과 키보드 후보 목록
- 지원 종목 테이블: 이름, 코드, 합성 현재가, 합성 등락, 합성 거래량
- 관심종목과 최근 노트

전국 시장 전체 순위, 실제 거래대금 순위, 실제 코스피 지수처럼 보이는 가상 지표를 만들지 않는다. 필요하면 `데모 종목 내 변화`로 범위를 표시한다.

### 6.2 종목 상세

데스크톱 구성:

```text
기업명 / 종목코드                  관심종목   비교에 추가   노트
시세 시뮬레이션                    재생 상태 / 배속 / 일시정지
가격 / 등락                       출처별 마지막 수신 시각

[개요] [재무] [공시]

캔들 차트와 거래량                 10단계 호가
기간 선택                         최근 체결

실제 재무 요약                    내 리서치 노트
```

차트는 보기 기간과 캔들 간격을 구분한다. `1일 캔들 + 최근 1년`과 `1분 캔들 + 데모 세션`은 다른 모드다. 한투 실시간 모드의 1분 캔들은 구독 이후 직접 집계한 범위만 우선 지원한다. 확보하지 않은 과거 분봉을 만들어내지 않는다.

호가창:
- 매도 10단계, 매수 10단계 또는 제공된 유효 단계만 표시
- 가격, 잔량, 잔량 막대의 의미를 명확히 구분
- 매수/매도 호가와 체결 방향을 같은 값으로 오인하지 않는다.
- 수량 0인 단계와 미제공 단계를 구분한다.

체결 목록:
- 최근 200개만 화면에 보이고 내부 버퍼도 상한을 둔다.
- 시간, 체결가, 체결량 표시
- 가격 상승/하락을 매수/매도 공격 주체라고 단정하지 않는다.
- 네트워크 복구 후 누락 가능 구간에는 상태 배지를 표시한다.

### 6.3 재무

상단 필터는 `연간/분기`, `연결/별도`, 사업연도다. 데이터가 연결 기준인데 별도 필터를 표시하는 식의 불일치는 허용하지 않는다.

요약: 매출, 영업이익, 당기순이익, 영업이익률. 상세: 자산, 부채, 자본, 영업/투자/재무 현금흐름.

각 값의 상세 설명에는 원래 단위, 보고서명, 접수번호, 계정명, 수집일, 직접 제공/계산 여부를 포함한다. 반올림한 `조 원` 표시와 원 단위 확인을 함께 지원한다.

숫자가 없는 곳은 `—`와 사유를 보여준다. 0으로 채우거나 이전 기간 숫자를 복사하지 않는다. 분기 계산 규칙은 문서 03을 따른다.

### 6.4 공시

제목, 제출일, 보고서 종류, 정정 여부를 표시한다. 정정 공시는 숨기지 않는다. 공시 제목이 클릭되면 허용된 DART 원문 주소로 이동한다. 외부 페이지를 iframe으로 강제 삽입하거나 원문 전체를 자체 서비스처럼 복제하지 않는다.

`공시 발표가 합성 주가에 미친 영향` 같은 해석은 금지한다.

### 6.5 기업 비교

최대 3개 기업만 허용한다. 매출, 영업이익, 순이익, 영업이익률, 자산, 부채, 자본을 표와 선택형 차트로 비교한다.

- 같은 사업연도와 연결/별도 기준을 적용한다.
- 특정 기업이 연결 데이터를 제공하지 않으면 그 기업의 칸을 미제공으로 둔다. 몰래 별도로 대체하지 않는다.
- 결산기간과 통화가 다르면 비교 불가 또는 별도 표시한다.
- 단순 규모 차이를 투자 우열처럼 표현하지 않는다.

### 6.6 리서치 노트

필드: 제목, 관련 종목, 핵심 생각, 근거, 위험 요인, 확인할 일, 회고, 작성일, 수정일.

최초 버전은 일반 텍스트와 체크리스트다. 리치 텍스트 에디터, AI 작성, 파일 첨부는 넣지 않는다. 자동 저장은 `저장 중/저장됨/저장 실패`를 구분하고 입력 직후 이동해도 내용을 잃지 않게 한다.

게스트 저장 안내: `이 브라우저에만 저장됩니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다.` JSON 내보내기/가져오기와 로컬 초기화를 제공한다. 내보내기에는 실제 한투 시세가 포함되지 않도록 개인 텍스트 데이터만 허용한다.

2026-09-30 P3 구현 계약: 관심종목은 최초 빈 목록이며 홈/상세 별표와 `/watchlist`에서 저장한다. 이전 홈 `symbols` URL은 임시 목록으로 표시하고 명시적인 버튼으로만 저장 목록에 추가한다. 비교 화면의 재무는 현재 fixture 전용이다. 노트는 입력 600ms 후 자동 저장하고 포커스 이동/페이지 탐색 때 즉시 저장을 시도한다. 저장 실패·충돌 시 초안을 유지하고 최신본 읽기/사본 저장/텍스트 내보내기를 제공한다. 백업은 기존 기록에 추가하는 방식이며 가져온 노트는 새 ID를 사용한다. 초기화·삭제·미저장 초안 닫기는 화면에서 확인 후 수행한다. 이 동작들은 코드 작성 상태이며 실제 UI/저장 검증은 아직 하지 않았다.

### 6.7 데모 제어

최초 버전: 일시정지/재생, 1배/2배/4배, 초기화. 탐색 막대와 임의 시점 이동은 후속 성능 단계에서 구현한다.

탭을 숨기면 합성 가상 시간을 멈추고 돌아오면 이어서 재생한다. 오랫동안 숨겼다가 돌아왔다고 누적 이벤트 수십만 개를 한 번에 밀어 넣지 않는다.

## 7. UI 규칙

### 시각 방향
정보 밀도가 있는 리서치 도구로 만든다. 증권사 로고, 화면 자산, 고유 문구를 그대로 복제하지 않는다. 과한 그라디언트, 유리 효과, 네온, 의미 없는 장식 카드, 과장된 3D 요소는 사용하지 않는다.

- 데스크톱 작업 화면을 우선 완성하되 모바일에서도 핵심 흐름이 가능해야 한다.
- 기본 테마는 어두운 중립 배경, 밝은 텍스트, 얇은 경계선이다. 색상은 CSS 토큰으로 관리한다.
- 예시 토큰: 배경 `#0B0F14`, 패널 `#121821`, 경계 `#2B3543`, 본문 `#E6EBF2`, 보조 `#A6B2C3`, 강조 `#78A9FF`.
- 상승/하락은 국내 사용자를 위한 빨강/파랑 조합을 사용하되 `+/-`, 방향 아이콘과 텍스트를 함께 제공한다. 실제 대비는 구현 후 측정한다.
- 숫자는 tabular-nums, 오른쪽 정렬, 고정된 소수 자릿수 정책을 사용한다.
- 모서리 6~10px, 간격 4px 배수, 본문 14~16px를 시작점으로 한다.
- 폰트는 시스템 폰트를 기본으로 하며 네트워크 폰트 실패 때문에 빌드나 첫 화면이 막히지 않게 한다.

### 반응형
- 1280px 이상: 차트와 호가/체결 2열.
- 768~1279px: 우측 패널 축소 또는 하단 이동.
- 767px 이하: 시세, 차트, 호가, 재무를 세로 배열하고 호가/체결은 탭으로 전환.
- 넓은 재무 표와 캔들 수치표는 영역 내부 가로 스크롤을 허용한다. 전체 페이지 가로 넘침은 금지한다.

### 접근성과 조작
검색은 combobox 패턴, 표는 실제 table/caption, 필터는 명확한 label을 사용한다. 차트 옆에 핵심 값 표나 텍스트 대체 정보를 제공한다.

실시간 가격마다 `aria-live`를 읽지 않는다. 사용자가 업데이트를 멈출 수 있어야 한다. 키보드 포커스를 실시간 변경 때문에 이동시키지 않는다. 반짝임을 제한하고 `prefers-reduced-motion`을 존중한다. 공시 링크는 외부 이동임을 표시한다.

2026-09-30 P6-A 구현 계약(실행 미검증): 홈/상세의 `화면 고정`으로 현재가·1분 캔들·호가·체결·표시 시각/상태를 함께 고정한다. 고정한 값은 최신 시세가 아니며 고정 시각은 실제 시각으로, 합성 가상 시각/원천 체결 시각과 구분한다. 수신·집계는 기존 정책대로 유지하고, 최신 값 한 번 반영은 고정값만 교체한다. 자동 갱신 복귀나 명시적인 재생·연결 제어는 고정을 해제한다. 앱 안의 화면 이동/숨긴 탭 복귀에는 고정을 유지하며 새로고침에는 남기지 않는다.

상세의 수치표 선택은 화면 전체를 고정하고 선택한 기간의 모든 캔들을 최신순으로 20개씩 제공한다. 날짜·KST 시작 시각·OHLC·정확한 거래량, caption과 행/열 header를 사용한다. 자동 갱신 복귀 시 차트로 돌아가며, 표 갱신·종목/기간 변경 시 첫 페이지로 이동한다. 고정 당시 빈 자료는 예시로 채우지 않는다. 일봉 조회/재무/공시는 고정 범위 밖이다. 반응형·키보드·스크린리더 검증은 사용자 요청 후 수행한다.

## 8. 대표 사용자 인수 시나리오

1. 로그인 없이 홈 접속 → 합성 시세 표시를 확인 → 삼성전자 검색 → 상세 진입.
2. 데모 재생 → 호가/체결/캔들 확인 → 일시정지 → 값 변화가 멈추는지 확인.
3. 재무 탭 → 연결 연간 실적 → 원문 링크 확인 → 분기 전환과 계산 표시 확인.
4. 두 기업 비교 → 같은 연도와 기준 확인 → 데이터가 없는 칸의 사유 확인.
5. 관심종목 추가 → 노트 작성 → 새로고침 → 본인의 기록 유지 확인.
6. 네트워크 실패 → 이전 캐시가 있다면 오래됨 표시 → 새 수치를 조작하지 않음.

모든 시나리오는 문서 05의 테스트 ID와 연결한다.
